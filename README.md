ПЕРВЫЙ ЗАПУСК И ДЕМОНСТРАЦИЯ

При старте приложение создаёт SQLite-базу garden.sqlite3, если её ещё нет. Если соответствующие списки пусты, добавляются демонстрационный проект и workflow Full Security Audit.

    Открываем Dashboard.
    Нажмаем Run audit.
    Ждем статуса success или failed.
    Открываем Security Reports.
    Переключаем All, SECRET, SCA и SAST для фильтрации.
    Нажмимаем Download JSON, чтобы сохранить отображаемый набор находок.
    Открываем Executions для просмотра списка сохранённых запусков.

success означает, что workflow выполнился без ошибки. Это не означает отсутствие уязвимостей.

ПОМОЩНИК «СКРЕПКА»
================================================

1. Назначение и границы
Скрепка объясняет результаты аудита безопасности и предлагает порядок исправлений.
Сам поиск проблем выполняют сканеры в scanners.py: секреты, уязвимые зависимости
по локальной базе и признаки опасного Kotlin-кода. Security Reports показывает
результаты. AI не заменяет сканеры и не гарантирует безопасность проекта.

2. Реализованные функции
- Помощник в правом нижнем углу: модель 3d/Helper1.obj и Helper1.mtl,
  освещение и анимация с учётом prefers-reduced-motion.
- Чат: выбор завершённого аудита, вопрос о находках, сохранение вопросов
  и ответов в SQLite вместе с запуском; показ последнего сохранённого ответа.
- AI Analysis: автоматическое заключение в сценарии; результат сохраняется
  в поле ai запуска. Новая AI-нода соединяется с конечными нодами сценария,
  после добавления сценарий нужно сохранить.
- Ответ API проверяется по JSON-контракту и допустимым ID находок.
- Если 3D не загрузится, остаётся кнопка чата.

3. Основной запуск через Shugg
Set-Location "C:\Users\resha\Desktop\garden"
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start-shugg.ps1
Установку зависимостей достаточно выполнить при подготовке окружения или их изменении.
PowerShell требует префикс .\ для запуска скрипта из текущей папки.

!!!Если политика PowerShell запрещает запуск скриптов, разреши его только
для текущего окна и повтори запуск: !!!
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\start-shugg.ps
